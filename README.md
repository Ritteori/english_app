# Wordwave — PWA для изучения английских слов голосом

Локальное веб-приложение без backend и без GPU. Все наборы и статистика хранятся в IndexedDB браузера.

## Запуск через Docker (Linux / Windows)

Требуется Docker Desktop на Windows или Docker Engine + Compose plugin на Linux.

```bash
docker compose up -d --build
```

Откройте **http://localhost:8080**.

Остановка:

```bash
docker compose down
```

Данные словарей хранятся в браузере, а не в контейнере. Пересборка или удаление контейнера не удаляет IndexedDB. Для резервной копии нажмите иконку экспорта в правом верхнем углу.

## Запуск без Docker

Можно использовать любой статический HTTP-сервер из каталога проекта. Например:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080. На Windows подойдёт `py -m http.server 8080`.

## Публикация и iPhone

Для микрофона нужен защищённый контекст: HTTPS (или localhost на самом компьютере). Опубликуйте содержимое проекта на GitHub Pages или Vercel, затем откройте HTTPS-ссылку в Safari на iPhone и выберите «Поделиться → На экран Домой».

Чтобы голосовое распознавание работало в Safari, проверьте:

- Разрешён ли микрофон для сайта в настройках Safari.
- Включена ли Siri в iOS: Web Speech recognition в Safari использует системный движок Apple.
- Есть ли подключение к интернету: браузерное распознавание может зависеть от сетевого сервиса.

У WebKit встречаются версии iOS, где повторный запуск `SpeechRecognition` после озвучки может зависать. В приложении предусмотрены ручная кнопка запуска, повтор, watchdog и текстовый ввод ответа. Гарантировать полностью бесшовный hands-free режим на каждой версии iOS нельзя.

## Импорт слов

Поддерживаются строки формата:

```text
покидать - abandon
достигать: achieve
осведомлённый<TAB>aware
поддерживать — to maintain
```

Первая колонка — русский вопрос, вторая — английский перевод. Несколько вариантов перевода можно указывать через `;` или `|`:

```text
получать - get; receive; obtain
```

Максимум 5 000 уникальных строк в одном наборе. Повторяющиеся русские слова объединяются в одну карточку с вариантами ответа.

## Хранение и перенос данных

- IndexedDB — отдельная база для каждого браузера и домена.
- Кнопка со стрелкой вниз экспортирует все наборы и статистику в один JSON.
- Кнопка со стрелкой вверх импортирует JSON в другой браузер или на другое устройство.
- При импорте создаются новые наборы; существующие не перезаписываются.

## Технические ограничения

Распознавание речи выполняется браузером через `SpeechRecognition` / `webkitSpeechRecognition`, а озвучка — через `speechSynthesis`. Поддержка и доступность распознавания зависят от браузера, ОС, системных настроек и сети. На браузере без SpeechRecognition можно отвечать через ручное поле.
